Cluster Mapping

ฟังก์ชัน Cluster Attribute / Command Scale

Flow การทำงาน

  1. 1commission_with_code() → เพิ่ม Hub เข้า fabric
  2. 2_discover() → สแกน endpoint + cluster
  3. 3subscribe_events(ATTRIBUTE_UPDATED)
  4. 4Sensor เปลี่ยน → Hub push → _handle_attr_update()
  5. 5→ เขียน TimescaleDB + broadcast WebSocket
  6. 6UI สั่งงาน → send_device_command() → Zigbee
  7. 7Device ตอบ → push state → UI reconcile

Hybrid Pattern

class DeviceRouter:
    """Matter หลัก · Tuya fallback"""
    async def send(self, dev_id, action, val):
        backend = self.route.get(dev_id, "matter")
        if backend == "matter":
            return await self.matter.set_onoff(
                dev_id, val)
        return await self.tuya.send_command(
            dev_id, action, val)

อุปกรณ์ที่ Matter มองเห็น → ใช้ Matter (เร็ว, local)
ตัวที่ M1 ไม่ bridge ออกมา → fallback Tuya Cloud

Authentication & 2FA

┌─ STEP 1 ────────────────────────────────────────┐
│ POST /api/auth/login  (username + password)     │
│   ├─ เช็ค lockout (5 ครั้ง/15 นาที จาก audit)    │
│   ├─ argon2 verify + rehash ถ้า params เปลี่ยน   │
│   └─ ถ้า totp_enabled → mfa_token (TTL 5 นาที)   │
└──────────────────┬──────────────────────────────┘
                   ▼
┌─ STEP 2 ────────────────────────────────────────┐
│ POST /api/auth/mfa/verify  (mfa_token + code)   │
│   ├─ 6 หลัก → pyotp.verify(valid_window=1)      │
│   └─ อื่นๆ → backup code (UPDATE … RETURNING)   │
└──────────────────┬──────────────────────────────┘
                   ▼
┌─ SESSION ───────────────────────────────────────┐
│ access_token   → sessionStorage   (20 นาที)     │
│ refresh_token  → httpOnly cookie  (14 วัน)      │
│                  Secure · SameSite=Strict       │
│                  path=/api/auth                 │
└─────────────────────────────────────────────────┘

ข้อควรระวัง (Gotchas)

ปัญหา สาเหตุ ทางแก้

⚠ Tuya Cloud

  • • Trial Edition หมดอายุทุก 30 วัน — ต้อง extend ใน Tuya IoT Platform
  • • Rate limit — อย่า poll ถี่กว่า 10 วิ/device
  • • ควรใช้ Pulsar Message Service รับ event push แทน polling

🔒 Security

  • • อย่า cache /api/* ใน service worker
  • • อย่า log password / TOTP / token ลง detail
  • • /api/commission = LAN only
  • • access token ใน sessionStorage ไม่ใช่ localStorage
